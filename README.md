# 🤖 Репост Бот: Telegram ➔ MRIYU

Потужний, автономний репост-бот для автоматичної трансляції публікацій із вказаного Telegram-каналу до соціальної мережі **[MRIYU](https://mriyu.com)** згідно з офіційною документацією [MRIYU Bot API](https://mriyu.com/wiki/bot-api).

---

## 🌟 Ключові можливості

- **Спільний Python-рушій (Core Engine):**
  - Працює у фоновому режимі 24/7.
  - Автоматичне опитування Telegram-каналу з налаштовуваним інтервалом.
  - Захист від дублікатів (SQLite база збереження вже опублікованих постів).
  - Підтримка тексту з розміткою, фотографій та інлайн-кнопок.
- **3 зручні інтерфейси керування:**
  1. 📱 **Web + JS (Мобільний та десктопний браузер):** Спеціально оптимізовано для запуску на **Android (Termux)**. Працює на вбудованому сервері стандартної бібліотеки Python — **нуль важких залежностей, не потребує компіляторів, Rust, Pydantic чи FastAPI!**
  2. 💻 **Python Desktop GUI:** Графічний інтерфейс на **PySide6 (Qt)** для комп'ютера.
  3. ⌨️ **Python CLI:** Інтерактивне та командне консольне меню для термінала або VPS.
- **Гнучкі налаштування джерела (Telegram):**
  - **Web-скрейпер публічних каналів:** Працює одразу без будь-яких API-ключів, номерів телефону чи токенів Telegram.
  - **Telegram Bot API:** Опціональний режим з використанням токена Telegram-бота.
  - Налаштування кількості синхронізації на першому старті (0 = лише майбутні пости, або N останніх).
- **Фільтрація та модерація контенту:**
  - Чорний список слів (автоматичний пропуск рекламних або небажаних постів).
  - Білий список слів (публікація лише постів з відповідними темами).
  - Фільтри за довжиною тексту (мінімум/максимум символів).
  - Дозвіл/заборона фото або суто текстових повідомлень.
  - Фільтрація пересланих постів та постів із зовнішніми посиланнями.
- **Форматування та заміна тексту:**
  - Автоматична конвертація форматування Telegram у розмітку MRIYU (`**жирний**`, `__курсив__`, `[текст](посилання)`, `` `код` ``).
  - Додавання кастомної шапки (префікса) та підвалу (суфікса).
  - Додавання клікабельного посилання на першоджерело у Telegram.
  - Додавання інтерактивної інлайн-кнопки під постом.
  - Словник автозаміни слів та регулярних виразів.

## 📱 Швидкий запуск на Android (Termux)

Завдяки переходу на вбудований багатопотоковий сервер стандартної бібліотеки Python, бот **не вимагає Rust, maturin, pydantic чи fastapi**, які викликали помилки збірки на Android Termux (Python 3.14).

Єдина бібліотека, що потрібна — це `requests`.

### Команди для запуску в Termux:
```bash
pkg update -y && pkg install -y python git

cd "$HOME"

# Клонування або перехід у папку проєкту
if [ -d tg2mriyu-repost-bot/.git ]; then
    cd tg2mriyu-repost-bot
    git pull
else
    git clone https://github.com/PraydE007/tg2mriyu-repost-bot.git
    cd tg2mriyu-repost-bot
fi

# Встановлення requests
pip install -r requirements.txt

# Запуск бота та веб-панелі
chmod +x start_android.sh
./start_android.sh
```

Після запуску відкрийте браузер на смартфоні за адресою:
👉 **`http://localhost:8080`**

## 💻 Запуск на Комп'ютері (Windows / Linux / macOS)

### 1. Встановлення залежностей
```bash
pip install -r requirements.txt
```
*(Якщо ви хочете використовувати віконний GUI на комп'ютері: `pip install -r requirements-gui.txt`)*

### 2. Варіанти запуску:

#### Варіант А: Web-інтерфейс (Рекомендовано)
```bash
python run_server.py
```
Відкрийте в браузері: `http://localhost:8080`

#### Варіант Б: Консольний інтерфейс (CLI)
```bash
python run_cli.py
```
Швидкі команди CLI:
- `python run_cli.py status` — показати статус і статистику
- `python run_cli.py run` — запустити рушій у терміналі
- `python run_cli.py test-tg <канал>` — протестувати зчитування каналу
- `python run_cli.py test-mriyu <токен>` — протестувати токен MRIYU та отримати список доступних каналів
- `python run_cli.py logs` — переглянути останні логи

#### Варіант В: Графічний інтерфейс (GUI на ПК)
```bash
python run_gui.py
```

*(На Windows також можна двічі клікнути файл `start_windows.bat`)*

## 🔑 Налаштування зв'язки з MRIYU

1. Перейдіть у соцмережу MRIYU в розділ **«Розробникам» ➔ «Боти»** (`https://mriyu.com/developers?bots`).
2. Натисніть **«Новий бот»**, вкажіть ім'я та адресу бота (адреса латиницею із закінченням `bot`, наприклад `repost_news_bot`).
3. Скопіюйте отриманий **токен бота**.
4. Створіть канал у MRIYU або відкрийте існуючий канал, зайдіть у **«Учасники» ➔ «Додати бота»** та додайте вашого бота (бот автоматично отримує права адміністратора для публікації).
5. Відкрийте панель нашого Репост Бота, вставте токен і натисніть кнопку **«🔍 Завантажити канали»**:
   - Бот автоматично перевірить токен і завантажить список усіх каналів, куди його додано!
   - Оберіть потрібний канал зі списку, і його `chat_id` підставиться автоматично.
6. Вкажіть назву джерела в Telegram (наприклад `durov` або `https://t.me/durov`).
7. Натисніть **«💾 Зберегти налаштування»** та **«▶ Запустити рушій»**!
